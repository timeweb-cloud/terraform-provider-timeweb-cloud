# twc_floating_ip (Data Source)

Data source that provides capability for filtering and selection floating ip. All parameters are filters, so you can use only needed

## Примеры использования

```terraform
# All parameters are filters, specify only the ones you need.
# id conflicts with the other filters — use one or the other.

data "twc_floating_ip" "example-by-id" {
  id = "968769c4-06ac-4b37-8e21-1fc8ff6c5a9b"
}

data "twc_floating_ip" "example-by-ip" {
  ip = "203.0.113.10"
}

data "twc_floating_ip" "example-by-filters" {
  availability_zone = "spb-3"
  ddos_guard        = true
  comment           = "Some floating IP"

  # Filter by the bound resource (`server`, `balancer`, `dbaas`)
  resource {
    type = "server"
    id   = "1234567"
  }
}
```
