# twc_s3_bucket (Data Source)

Data source that provides capability for filtering and S3 bucket selection. All parameters are filters, so you can use only needed

## Примеры использования

```terraform
# Select an existing S3 bucket by its full name.
# The bucket name is stored with a random prefix (full_name) — that is what we specify.
data "twc_s3_bucket" "example-s3-bucket" {
  name = "371bebbd-example-s3-bucket"
}
```
