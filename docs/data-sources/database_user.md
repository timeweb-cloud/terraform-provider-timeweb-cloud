# twc_database_user (Data Source)

Data source that provides bunch of useful parameters for filtering and suitable database user selection. All parameters are filters, so you can use only needed. Available OS [may be retrieved from API](https://api.timeweb.cloud/api/v1/databaseusers)

## Примеры использования

```terraform
# Lookup a database user inside a cluster by login.
# cluster_id is required; id / login are filters.
data "twc_database_user" "example-user" {
  cluster_id = twc_database_cluster.example-mysql-8.id

  login = "admin"
}

output "user_host" {
  value = data.twc_database_user.example-user.host
}
```
