# twc_database_replicas (Data Source)

Data source that provides the list of replicas of a database cluster. Replicas are created via the `replications` field of the cluster.

## Примеры использования

```terraform
# List replicas of a database cluster.
# Replicas are created via the replications field of the twc_database_cluster resource.
data "twc_database_replicas" "example-replicas" {
  cluster_id = twc_database_cluster.example-redis.id
}

# replicas — list: id, db_id, status, local_ip, disk { size, used }
output "replica_local_ips" {
  value = [for r in data.twc_database_replicas.example-replicas.replicas : r.local_ip]
}
```
