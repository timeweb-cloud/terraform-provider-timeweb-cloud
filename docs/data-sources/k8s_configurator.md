# twc_k8s_configurator (Data Source)

Configurator data source that provides information about available hardware parameters with their restrictions with filtering and selection suitable one. All parameters are filters, so you can use only needed. Available configurators [may be retrieved from API](https://api.timeweb.cloud/api/v1/configurator/servers)

## Примеры использования

```terraform
# Select K8S configurator for worker nodes in a specific location.
# A configurator lets you build custom node configuration (cpu/ram/disk)
# within its requirements instead of picking a fixed preset.
data "twc_k8s_configurator" "example-k8s-configurator" {
  location = "ru-1"

  # Node type the configurator is selected for (master / worker)
  node_type = "worker"

  # Preset type: premium, dedicated_cpu or gpu
  preset_type = "premium"
}

# Use the configurator to build a cluster with custom master configuration
resource "twc_k8s_cluster" "example-k8s-cluster" {
  name = "example-cluster"

  high_availability = false
  version           = "v1.31.0"
  network_driver    = "flannel"

  configuration {
    configurator_id = data.twc_k8s_configurator.example-k8s-configurator.id
    cpu             = 2
    ram             = 4096      # multiple of 1024
    disk            = 10 * 1024 # multiple of 5120
  }
}
```

## Schema

### Optional

- `cpu_frequency` (String) CPU frequency for the created server (`3.3`)
- `location` (String) Location for the created server. Code location map to availability zone: `ru-1` — SPB (spb-3), `ru-3` — MSK (msk-1), `nl-1` — AMS (ams-1). When server was created all new presets or configuration may be only chosen from same location
- `node_type` (String) Node type (`master`, `worker`)
- `preset_type` (String) Preset type for created node (`premium`, `dedicated_cpu`, `gpu`)

### Read-Only

- `disk_type` (String, Deprecated) Disk type for the created server (`ssd`, `nvme`, `hdd`)
- `id` (String) The ID of this resource.
- `requirements` (Block List) Configuration limitations for specified configurator (see [below for nested schema](#nestedblock--requirements))
