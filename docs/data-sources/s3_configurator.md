# twc_s3_configurator (Data Source)

Configurator data source that provides information about available S3 configurations with their restrictions with filtering and selection suitable one. All parameters are filters, so you can use only needed.

## Примеры использования

```terraform
# Select a cold storage configurator from the ru-1 location
data "twc_s3_configurator" "example-s3-configurator" {
  location      = "ru-1"
  storage_class = "cold" # hot | cold
  disk_type     = "nvme"
}

# Example of using the configurator in an S3 bucket configuration
resource "twc_s3_bucket" "example-s3-bucket" {
  name = "example-s3-bucket"
  type = "private"

  configuration {
    configurator_id = data.twc_s3_configurator.example-s3-configurator.id
    disk            = 2048
  }
}
```
