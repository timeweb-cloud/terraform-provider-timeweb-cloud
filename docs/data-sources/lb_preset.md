# twc_lb_preset (Data Source)

Data source that provides bunch of useful parameters for filtering and suitable preset selection. All parameters are filters, so you can use only needed. Available presets [may be retrieved from API](https://api.timeweb.cloud/api/v1/presets/k8s)

## Примеры использования

```terraform
# Select a load balancer preset for ~10K RPS priced between 100 and 200 rub.
# All parameters are filters, specify only the ones you need.
data "twc_lb_preset" "example-lb-preset" {
  location            = "ru-1"
  requests_per_second = "10K"

  price_filter {
    from = 100
    to   = 200
  }
}

# Using the selected preset when creating a load balancer
resource "twc_lb" "example-lb" {
  name = "example-lb"

  algo = "roundrobin"

  preset_id = data.twc_lb_preset.example-lb-preset.id
}
```
