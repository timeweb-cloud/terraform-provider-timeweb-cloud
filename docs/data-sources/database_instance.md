# twc_database_instance (Data Source)

Data source that provides bunch of useful parameters for filtering and suitable database instance selection. All parameters are filters, so you can use only needed. Available OS [may be retrieved from API](https://api.timeweb.cloud/api/v1/databaseinstances)

## Примеры использования

```terraform
# Lookup a database instance (database) inside a cluster by name.
# cluster_id is required; id / name are filters.
data "twc_database_instance" "example-instance" {
  cluster_id = twc_database_cluster.example-mysql-8.id

  name = "example"
}

output "instance_owner_id" {
  value = data.twc_database_instance.example-instance.owner_id
}
```
