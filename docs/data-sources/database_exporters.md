# twc_database_exporters (Data Source)

Data source that provides the list of Prometheus metric exporters of a database cluster.

## Примеры использования

```terraform
# List Prometheus metric exporters of a database cluster
data "twc_database_exporters" "example-exporters" {
  cluster_id = twc_database_cluster.example-mysql-8.id
}

# exporters — list: id, replica_id, login, password (sensitive)
output "exporter_ids" {
  value = [for e in data.twc_database_exporters.example-exporters.exporters : e.id]
}
```
