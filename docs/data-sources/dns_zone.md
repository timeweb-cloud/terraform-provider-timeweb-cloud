# twc_dns_zone (Data Source)

Data source that provides capability for filtering and domain zone selection. All parameters are filters, so you can use only needed

## Примеры использования

```terraform
# Select the zone named "example.com"
data "twc_dns_zone" "example-zone" {
  name = "example.com"
}

# Usage example of the selected zone: an AAAA record for the zone root with the value ::1
resource "twc_dns_rr" "example-resource-record" {
  zone_id = data.twc_dns_zone.example-zone.id

  name  = "@"
  type  = "AAAA"
  value = "::1"
}
```
