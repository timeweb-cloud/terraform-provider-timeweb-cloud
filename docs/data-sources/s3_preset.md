# twc_s3_preset (Data Source)

Data source that provides bunch of useful parameters for filtering and suitable preset selection. All parameters are filters, so you can use only needed. Available presets [may be retrieved from API](https://api.timeweb.cloud/api/v1/presets/storages)

## Примеры использования

```terraform
# Select a hot 10 GB preset from the ru-1 location
# with a price in the range from 50 to 100 RUB.
data "twc_s3_preset" "example-s3-preset" {
  location      = "ru-1"
  storage_class = "hot" # hot | cold (cold — for a cold bucket)

  disk = 10 * 1024

  price_filter {
    from = 50
    to   = 100
  }
}

# Example of using the selected preset
resource "twc_s3_bucket" "example-s3-bucket" {
  name      = "example-s3-bucket"
  type      = "private"
  preset_id = data.twc_s3_preset.example-s3-preset.id
}
```

## Schema

### Optional

- `description_short` (String) Short description of specified preset
- `disk` (Number) Disk size of specified preset
- `location` (String) Location for the created storage (`ru-1`, `ru-2`, `de-1`, `kz-1`). When storage was created all new presets or configuration may be only chosen from same location
- `price_filter` (Block List, Max: 1) Price filter for select preset in specified price range (see [below for nested schema](#nestedblock--price_filter))
- `storage_class` (String) Storage class of the preset (`hot`, `cold`). Use `cold` to select a preset for a cold bucket

### Read-Only

- `id` (String) The ID of this resource.
- `price` (Number) Price of specified preset
