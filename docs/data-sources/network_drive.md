# twc_network_drive (Data Source)

Data source that provides bunch of useful parameters for filtering and suitable network disks selection. All parameters are filters, so you can use only needed.

## Примеры использования

```terraform
# All parameters are filters, specify only the ones you need

data "twc_network_drive" "example-by-name" {
  name = "Example network drive"
}

data "twc_network_drive" "example-by-filters" {
  location          = "ru-1"
  availability_zone = "spb-3"
  type              = "nvme" # disk type: nvme, hdd
  size              = 20     # size in GB
}
```
