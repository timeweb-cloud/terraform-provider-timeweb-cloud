# twc_router_dnat_rule (Resource)

Resource for describing a DNAT (port-forwarding) rule of a virtual router. The API has no update operation for DNAT rules, so any change recreates the rule.

## Примеры использования

```terraform
# Forward inbound TCP/UDP traffic from public IP:80 to private host:8080.
# DNAT rules have no update operation in the API — any change recreates the rule.
resource "twc_router_dnat_rule" "example-dnat-rule" {
  router_id = twc_router.example-router.id

  protocol = "tcp_udp" # "tcp", "udp" or "tcp_udp" (defaults to tcp_udp)

  public_ip   = "203.0.113.10"
  public_port = "80" # single port; remove the line to forward all ports

  local_ip   = "192.168.0.5"
  local_port = "8080" # single port; remove the line to forward all ports
}
```

## Schema

### Required

- `local_ip` (String) Local (private) IPv4 the traffic is forwarded to
- `public_ip` (String) Public IPv4 that receives the incoming traffic
- `router_id` (String) ID of the target router

### Optional

- `local_port` (String) Local port. Single port ("80") or omitted to forward all ports
- `protocol` (String) Rule protocol: "tcp", "udp" or "tcp_udp"
- `public_port` (String) Public port. Single port ("80") or omitted to match all ports

### Read-Only

- `id` (String) The ID of this resource.
