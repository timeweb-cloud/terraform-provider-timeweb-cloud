# twc_s3_user (Resource)

Resource for managing S3 service accounts (S3 users). Provides an isolated pair of access/secret keys scoped to the account's object storage

## Примеры использования

```terraform
# S3 user (service account) — an isolated pair of access keys
# for the account's object storage
resource "twc_s3_user" "example-s3-user" {
  # Name: Latin letters, digits and the symbols = + , . @ - _ (3-64 characters)
  name = "example-s3-user"

  # Status: active (default) or inactive.
  # inactive disables the user's access keys.
  status = "active"
}

# Access keys are available as computed attributes (sensitive)
output "example_s3_user_access_key" {
  value     = twc_s3_user.example-s3-user.access_key
  sensitive = true
}

output "example_s3_user_secret_key" {
  value     = twc_s3_user.example-s3-user.secret_key
  sensitive = true
}
```

## Schema

### Required

- `name` (String) Name for the S3 user. May contain only Latin letters, digits and the characters `= + , . @ - _` (3-64 chars)

### Optional

- `status` (String) Status of the S3 user (`active`, `inactive`). Toggling to `inactive` disables the user's access keys

### Read-Only

- `access_key` (String, Sensitive) Access key for the S3 user
- `id` (String) The ID of this resource.
- `secret_key` (String, Sensitive) Secret key for the S3 user
