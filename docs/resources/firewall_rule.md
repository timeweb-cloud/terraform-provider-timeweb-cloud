# twc_firewall_rule (Resource)

Resource for describing needed firewall rule and provides actual information about its status

## Примеры использования

```terraform
# Create a firewall group
resource "twc_firewall" "example-firewall" {
  name        = "example-firewall"
  description = "Some example firewall"
}

# Allow incoming TCP on port 80 from any source
resource "twc_firewall_rule" "allow-http" {
  firewall_id = twc_firewall.example-firewall.id
  description = "Allow HTTP from anywhere"

  direction = "ingress"
  # port — a string: a single port ("80") or a range ("8000-9000")
  port     = "80"
  protocol = "tcp"
  cidr     = "0.0.0.0/0"
}

# Allow a range of ports over TCP on IPv6 (protocol: tcp6/udp6/icmp6 for IPv6)
resource "twc_firewall_rule" "allow-range-ipv6" {
  firewall_id = twc_firewall.example-firewall.id
  description = "Allow app ports over IPv6"

  direction = "ingress"
  port      = "8000-9000"
  protocol  = "tcp6"
  cidr      = "::/0"
}

# Allow outgoing ICMP (for ping); the port is not specified for icmp
resource "twc_firewall_rule" "allow-icmp-egress" {
  firewall_id = twc_firewall.example-firewall.id
  description = "Allow outgoing ICMP"

  direction = "egress"
  protocol  = "icmp"
  cidr      = "0.0.0.0/0"
}
```

## Schema

### Required

- `direction` (String) Rule direction (`ingress`, `egress`)
- `firewall_id` (String) ID of target firewall
- `protocol` (String) Rule protocol (`tcp`, `udp`, `icmp`, `tcp6`, `udp6`, `icmp6`)

### Optional

- `cidr` (String) Rule CIDR
- `description` (String) Description for firewall
- `port` (String) Port when rule protocol is TCP or UDP. Can be a single port ("80") or a range ("8000-9000")

- `id` (String) The ID of this resource.
