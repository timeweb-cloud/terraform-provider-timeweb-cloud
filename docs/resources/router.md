# twc_router (Resource)

Resource for describing virtual router

## Примеры использования

```terraform
# Select a router preset by price
data "twc_router_preset" "example-router-preset" {
  location = "ru-3"

  price_filter {
    from = 0
    to   = 1000
  }
}

# VPC network that the router will manage
resource "twc_vpc" "example-vpc" {
  name        = "Example VPC"
  description = "Some example VPC"
  subnet_v4   = "192.168.0.0/24"
  location    = "ru-3"
}

# Floating IP that becomes the router's public address
resource "twc_floating_ip" "example-router-ip" {
  availability_zone = "msk-1"
}

# Virtual router managing a single network with DHCP and SNAT enabled
resource "twc_router" "example-router" {
  name      = "example-router"
  comment   = "Some example router"
  preset_id = data.twc_router_preset.example-router-preset.id

  # networks block — TypeSet: list all networks managed by the router.
  # id holds the VPC identifier (pvc).
  networks {
    id = twc_vpc.example-vpc.id
    # DHCP for this network. If not set, the current DHCP state is kept
    is_dhcp_enabled = true
    # Source NAT (SNAT) IPv4 for the network's outbound traffic (optional).
    # Must be one of the router's own IPs from the ips block.
    # Remove the line to disable SNAT for the network.
    nat_ip = twc_floating_ip.example-router-ip.ip
  }

  # Public IPs of the router
  ips {
    ip = twc_floating_ip.example-router-ip.ip
  }
}

# NAT gateway for a private K8S cluster: the router orders a new floating IP
# itself (create_ip) and uses it as SNAT for the cluster network.
resource "twc_vpc" "k8s-vpc" {
  name      = "k8s-vpc"
  subnet_v4 = "192.168.10.0/24"
  location  = "ru-3"
}

resource "twc_router" "k8s-nat-router" {
  name      = "k8s-nat-router"
  preset_id = data.twc_router_preset.example-router-preset.id

  networks {
    id = twc_vpc.k8s-vpc.id
  }

  ips {
    # Real address is stored in the state; "create_ip" does not produce a diff
    ip = "create_ip"
    nat {
      id = twc_vpc.k8s-vpc.id
    }
  }

  # Fail creation if the daily floating IP limit is exhausted
  # (instead of creating the router without an IP)
  nat_required = true

  # Delete the ordered floating IP together with the router
  delete_ips_on_destroy = true
}

# Port forwarding to the router's IP ordered with create_ip: reference
# public_ip (ips[0].ip is the literal "create_ip" at plan time)
resource "twc_router_dnat_rule" "k8s-ingress" {
  router_id = twc_router.k8s-nat-router.id
  protocol  = "tcp"

  public_ip   = twc_router.k8s-nat-router.public_ip
  public_port = "443"

  local_ip   = "192.168.10.10"
  local_port = "443"
}
```

## Schema

### Required

- `name` (String) Router name
- `networks` (Block Set, Min: 1) Param that indicates which local-networks router will manage (see [below for nested schema](#nestedblock--networks))
- `preset_id` (Number) Preset ID for router

### Optional

- `comment` (String) Comment for creating router
- `delete_ips_on_destroy` (Boolean) Delete router floating IPs together with the router on destroy. By default they are only unbound and stay on the account (including the IP ordered with `create_ip`)
- `ips` (Block List, Max: 1) (see [below for nested schema](#nestedblock--ips))
- `nat_required` (Boolean) Router is required to have a NAT IP (e.g. as the NAT gateway for a private K8S cluster): when `ips.ip = "create_ip"` and the daily floating IP limit is exhausted, creation fails instead of creating the router without an IP. Takes effect only on creation
- `project_id` (Number) Id that allow you to attach router to project. Changing it forces router re-creation
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))

### Read-Only

- `availability_zone` (String) Availability zone where router located
- `id` (String) The ID of this resource.
- `network_details` (List of Object) Actual parameters of networks managed by router (see [below for nested schema](#nestedatt--network_details))
- `public_ip` (String) Actual floating IPv4 of the router (the one ordered with `ips.ip = "create_ip"` too) — use it in references, e.g. as `public_ip` of `twc_router_dnat_rule`
- `status` (String) Router status

### Nested Schema for `networks`

Required:

- `id` (String) Id of the network managed by router (exactly you should place here pvc's id)

Optional:

- `is_dhcp_enabled` (Boolean) Params that indicated will router use DHCP for this network. If not set, the current DHCP state of the network is kept
- `nat_ip` (String) Source NAT (SNAT) IPv4 for this network. Must be the router's own floating IP (`ips.ip`). When set, outgoing traffic from the network is translated to this IP; when removed, SNAT is disabled for the network. With `ips.ip = "create_ip"` use the `ips.nat` block instead
