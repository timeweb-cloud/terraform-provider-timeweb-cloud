# twc_database_instance (Resource)

Resource for describing needed database instance and provides actual information about its status

## Примеры использования

```terraform
# Select a preset for the MySQL cluster
data "twc_database_preset" "example-db-preset" {
  location = "ru-3"
  type     = "mysql"
  disk     = 8 * 1024

  price_filter {
    from = 1000
    to   = 1500
  }
}

# Create example cluster of MySQL
resource "twc_database_cluster" "example-mysql-8" {
  name = "example_mysql_8"
  type = "mysql"

  preset_id = data.twc_database_preset.example-db-preset.id
}

# Create example instance (database) in previously created cluster.
# name — renaming recreates a MySQL database (the API forbids renaming it);
# PostgreSQL databases are renamed in place.
resource "twc_database_instance" "example-mysql-8-instance" {
  cluster_id = twc_database_cluster.example-mysql-8.id

  name        = "example"
  description = "Example database"
}

### PostgreSQL database with extensions

data "twc_database_preset" "example-postgres-preset" {
  location = "ru-3"
  type     = "postgres"
  # postgres17 requires at least 2 GB of RAM
  ram  = 2 * 1024
  disk = 20 * 1024
}

resource "twc_database_cluster" "example-postgres" {
  name      = "example_postgres"
  type      = "postgres17"
  preset_id = data.twc_database_preset.example-postgres-preset.id
}

resource "twc_database_user" "example-postgres-owner" {
  cluster_id = twc_database_cluster.example-postgres.id
  login      = "app_owner"
  password   = "Example-Pass-123"
  privileges = ["SELECT", "INSERT", "UPDATE", "DELETE"]
}

resource "twc_database_instance" "example-postgres-instance" {
  cluster_id = twc_database_cluster.example-postgres.id
  # PostgreSQL databases are renamed in place, without data loss
  name = "app"

  # Owner of the database, applied right at creation
  owner_id = twc_database_user.example-postgres-owner.id

  # Extensions installed into the database (PostgreSQL and RabbitMQ)
  extensions = ["pg_trgm", "uuid-ossp", "pgcrypto"]
  # To apply the same set to all databases of the cluster, set
  # extensions_is_global = true and declare the same extensions in every
  # twc_database_instance of the cluster

  # Time limits for operations (default 30m)
  timeouts {
    create = "45m"
  }
}

output "app_database_owner" {
  value = twc_database_instance.example-postgres-instance.owner_login
}

### Kafka topic with parameters

data "twc_database_preset" "example-kafka-preset" {
  location = "ru-3"
  type     = "kafka"
}

resource "twc_database_cluster" "example-kafka" {
  name      = "example_kafka"
  type      = "kafka"
  preset_id = data.twc_database_preset.example-kafka-preset.id
}

resource "twc_database_instance" "example-kafka-topic" {
  cluster_id = twc_database_cluster.example-kafka.id
  name       = "events"

  # Topic parameters (Kafka only). The number of partitions can only be increased
  config_parameters = {
    partitions     = 3
    retention_ms   = 604800000
    cleanup_policy = "delete"
  }
}
```

## Schema

### Required

- `cluster_id` (Number) Database cluster ID for which backup instance be created
- `name` (String) Name for database instance. PostgreSQL databases are renamed in place; for other database types the API forbids renaming, so changing it recreates the instance

### Optional

- `config_parameters` (Map of String) Topic parameters (only for Kafka), e.g. `partitions`, `retention_ms`, `cleanup_policy`, `compression_type`, `min_insync_replicas`. The number of partitions can only be increased
- `description` (String) Description for project
- `extensions` (Set of String) Set of extensions installed into the database (PostgreSQL: `pg_stat_statements`, `postgis`, `pgvector`, `uuid-ossp`, `pg_trgm`, `pgcrypto`, `hstore`, `citext`, `timescaledb` and others; RabbitMQ: plugins like `rabbitmq_mqtt`, `rabbitmq_shovel`). Supported only for PostgreSQL and RabbitMQ. `earthdistance` requires `cube`. `pgagent` is decommissioned: it can't be installed anew, an already installed one stays
- `extensions_is_global` (Boolean) Apply the same set of `extensions` to all databases of the cluster. Note: it changes extensions of other databases of the cluster, and `false` on any database resets the flag for all of them — when it is used, declare the same `extensions` and `extensions_is_global = true` in every `twc_database_instance` of the cluster
- `owner_id` (Number) ID of the admin (user) that owns this database instance (applicable to PostgreSQL)
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))

### Read-Only

- `id` (String) The ID of this resource.
- `owner_login` (String) Login of the admin (user) that owns this database instance
