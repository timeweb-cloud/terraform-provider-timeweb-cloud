# twc_database_backup_schedule (Resource)

Resource for describing needed database auto backup properties and schedule

## Примеры использования

```terraform
# Select a preset and create a cluster to schedule backups for
data "twc_database_preset" "example-db-preset" {
  location = "ru-1"
  type     = "mysql"
  disk     = 8 * 1024
}

resource "twc_database_cluster" "example-mysql-8" {
  name = "example_mysql_8"
  type = "mysql"

  preset_id = data.twc_database_preset.example-db-preset.id
}

# Automatic backup schedule for the cluster
resource "twc_database_backup_schedule" "example-schedule" {
  cluster_id = twc_database_cluster.example-mysql-8.id

  enabled = true

  # copy_count — the maximum number of stored copies
  copy_count = 5

  # interval — frequency: day | week | month
  interval = "week"

  # day_of_week — day of the week (1 = Monday .. 7), only used when interval = "week"
  day_of_week = 1

  # creation_start_at — date of the first backup (the API stores only the calendar date)
  creation_start_at = "2026-01-01T00:00:00"
}
```

## Schema

### Required

- `cluster_id` (Number) Database cluster ID for which database auto backups should be configured
- `copy_count` (Number) Maximum stored copy count
- `creation_start_at` (String) Creation date for first backup
- `interval` (String) Interval between auto backups (`day`, `week`, `month`)

### Optional

- `day_of_week` (Number) Day of the week when auto backup should be created. Allowed only for week interval, counting starts from 1 (Monday)
- `enabled` (Boolean) Enable auto backups

### Read-Only

- `id` (String) The ID of this resource.
