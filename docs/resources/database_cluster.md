# twc_database_cluster (Resource)

Resource for describing needed database cluster and provides actual information about its status

## Примеры использования

```terraform
### PostgreSQL cluster with config parameters

# Pick a preset matching the database type (presets are bound to a type and location)
data "twc_database_preset" "example-postgres-preset" {
  location = "ru-1"
  type     = "postgres"
  disk     = 8 * 1024
}

resource "twc_database_cluster" "example-postgres" {
  name = "example_postgres"
  type = "postgres"

  preset_id = data.twc_database_preset.example-postgres-preset.id

  # config_parameters — overrides for the database engine configuration parameters
  config_parameters = {
    max_connections = 100
  }

  # is_external_ip — access the cluster over an external (public) IP
  is_external_ip = true
  # is_secure_connection_enabled — enable SSL connection to the cluster
  is_secure_connection_enabled = true
}

### MySQL cluster

data "twc_database_preset" "example-mysql-preset" {
  location = "ru-1"
  type     = "mysql"
  disk     = 8 * 1024

  price_filter {
    from = 100
    to   = 500
  }
}

resource "twc_database_cluster" "example-mysql-8" {
  name = "example_mysql_8"
  type = "mysql"

  preset_id = data.twc_database_preset.example-mysql-preset.id

  # hash_type — how MySQL passwords are stored (caching_sha2 | mysql_native)
  hash_type = "caching_sha2"

  config_parameters = {
    auto_increment_increment = 3
  }
}

### Redis cluster with replicas

data "twc_database_preset" "example-redis-preset" {
  location = "ru-1"
  type     = "redis"
}

resource "twc_database_cluster" "example-redis" {
  name = "example_redis"
  type = "redis"

  preset_id = data.twc_database_preset.example-redis-preset.id

  # replications — number of replicas (not available for all database types/presets)
  replications = 1
}

### Clickhouse cluster with inline admin

# Some engines (for example clickhouse) require an admin at creation time.
# The admin block is create-only (ForceNew); the API does not return the password.
data "twc_database_preset" "example-clickhouse-preset" {
  location = "ru-1"
  type     = "clickhouse"
}

resource "twc_database_cluster" "example-clickhouse" {
  name = "example_clickhouse"
  type = "clickhouse"

  preset_id = data.twc_database_preset.example-clickhouse-preset.id

  admin {
    login = "admin"
    # for clickhouse: at least 10 characters, Latin letters, digits and the / + symbols
    password = "ExamplePass123/"
  }
}
```

## Schema

### Required

- `name` (String) Name for database cluster
- `preset_id` (Number) Preset ID for database cluster
- `type` (String) Type of database cluster (database engine). Validated against the API. Common values: `mysql`, `mysql5`, `postgres`, `redis`, `redis7`, `valkey`, `mongodb`, `clickhouse`, `opensearch`, `kafka`, `rabbitmq`. The chosen `twc_database_preset` must be of the same type

### Optional

- `admin` (Block List, Max: 1) Initial admin (user) created together with the cluster. Required by some engines (e.g. clickhouse). Credentials are not returned by the API, so this block is create-only. When set, the default admin/instance are kept (not removed). (see [below for nested schema](#nestedblock--admin))
- `availability_zone` (String) Availability zone for database cluster
- `config_parameters` (Map of String) Configuration parameters for database cluster
- `description` (String) Description for project
