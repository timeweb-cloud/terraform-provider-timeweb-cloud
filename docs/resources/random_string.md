# twc_random_string (Resource)

Resource that generates a random string. Lowercase letters (a-z) and digits (0-9) are always included; uppercase letters (A-Z) and special characters can be toggled via the upper and special arguments. The string is generated once on creation and stored in state. Changing symbol_count, upper or special forces a new resource to be created.

## Примеры использования

```terraform
# Generates a random string once on creation and stores it in state.
# Lowercase letters (a-z) and digits (0-9) are always included; uppercase letters
# and special characters are controlled by the upper and special flags.
# Changing symbol_count, upper or special recreates the resource.
resource "twc_random_string" "example" {
  symbol_count = 16   # length of the generated string
  upper        = true # add uppercase letters (A-Z)
  special      = true # add special characters (!@#$%^&*()-_=+[]{}<>:?)
}

# Example of using the generated string as a server name
data "twc_os" "example-os" {
  name    = "ubuntu"
  version = "22.04"
}

data "twc_presets" "example-preset" {
  price_filter {
    from = 300
    to   = 400
  }
}

resource "twc_server" "example-server" {
  name  = "server-${twc_random_string.example.result}"
  os_id = data.twc_os.example-os.id

  preset_id = data.twc_presets.example-preset.id
}
```

### Required

### Optional

- `upper` (Boolean) Include uppercase letters (A-Z) in the generated string. Defaults to true.
