# twc_router_static_route (Resource)

Resource for describing a static route of a virtual router. The API has no update operation for static routes, so any change recreates the route.

## Примеры использования

```terraform
# Route the 10.10.0.0/24 subnet via next hop 192.168.0.254.
# Static routes have no update operation in the API — any change recreates the route.
resource "twc_router_static_route" "example-static-route" {
  router_id = twc_router.example-router.id

  subnet  = "10.10.0.0/24"  # destination subnet in CIDR format
  nexthop = "192.168.0.254" # IPv4 of the next hop for this subnet
}
```
